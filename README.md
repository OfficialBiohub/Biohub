# BioHub Hosting — বাংলা ওয়েব হোস্টিং ডেমো 🌐🇧🇩

এটি একটি সম্পূর্ণ বাংলা ভাষায় তৈরি **ওয়েব হোস্টিং কোম্পানির ডেমো ওয়েবসাইট**। শুধুমাত্র HTML, CSS এবং JavaScript ব্যবহার করে বানানো হয়েছে — কোনো বিল্ড স্টেপ বা সার্ভার সাইড ডিপেন্ডেন্সি নেই।

## ✨ ফিচারসমূহ

- 🏠 **হেডার ও নেভিগেশন** — লোগো, মেনু, মোবাইল হ্যামবার্গার
- 💚 **হিরো সেকশন** — বাংলাদেশের জন্য বিশেষ অফার, দাম ১৯৯ টাকা/মাস থেকে শুরু
- 🟢 **সার্ভার স্ট্যাটাস** — রিয়েল-টাইম স্ট্যাটাস কার্ড
- ✨ **৬টি ফিচার** — দ্রুত গতি, ফ্রি SSL, ব্যাকআপ, বাংলা ২৪/৭ সাপোর্ট
- 💰 **প্রাইসিং প্ল্যান** — Starter / Business / Premium (মাসিক ↔ বার্ষিক টগল)
- 🔍 **ডোমেইন সার্চ** — `.com`, `.net`, `.org`, `.info`, `.com.bd` দাম সহ (ডেমো)
- ❓ **FAQ** — বাংলায় প্রশ্নোত্তর
- 📞 **যোগাযোগ ফর্ম** — ফর্ম ভ্যালিডেশন সহ
- 🦶 **ফুটার** — পেমেন্ট পদ্ধতি (bKash/Nagad/রকেট/কার্ড)
- 📱 **সম্পূর্ণ রেসপন্সিভ** — মোবাইল, ট্যাবলেট ও ডেস্কটপে সুন্দরভাবে কাজ করে

## 📁 ফাইল স্ট্রাকচার

```
.
├── index.html   # মূল পেজ
├── style.css    # ডিজাইন ও রেসপন্সিভ স্টাইল
├── script.js    # ইন্টার‌্যাক্টিভ ফিচার
└── README.md    # এই ফাইল
```

## 🚀 লোকালি চালানো

যেকোনো স্ট্যাটিক সার্ভার দিয়ে চালানো যায়। সবচেয়ে সহজ উপায়:

```bash
# Python দিয়ে
python3 -m http.server 3000 --bind 0.0.0.0

# অথবা Node.js দিয়ে (npx থাকলে)
npx serve .
```

তারপর ব্রাউজারে যান: `http://localhost:3000`

## 🌐 GitHub Pages-এ ফ্রি হোস্ট

1. রিপোর **Settings → Pages**-এ যান
2. Source হিসেবে `main` ব্রাঞ্চ ও `/ (root)` সিলেক্ট করুন
3. Save করুন — কয়েক মিনিটের মধ্যে লাইভ হয়ে যাবে
