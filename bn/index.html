বায়োহাব-এ স্বাগতম।

জীববিজ্ঞান বিষয়ক প্রকল্প, ডেটা ও টুলের একটি উন্মুক্ত ঠিকানা। এই পেজটি রিপোজিটরির সূচনাবিন্দু — ক্লোন করুন, এর উপর ভিত্তি করে নতুন কিছু গড়ুন, আর একে নিজের মতো করে সাজিয়ে নিন।

bash — biohub
# রিপোজিটরিটি ক্লোন করুন
git clone https://github.com/OfficialBiohub/Biohub.git
cd Biohub

# এই স্বাগত পেজটি নিজের কম্পিউটারে খুলুন
